A importância do HTML semântico

Publicado em 31 de julho de 2026

O HTML descreve a estrutura e o significado do conteúdo. Utilizar o elemento correto melhora a acessibilidade, a organização do código e os mecanismos de busca.

Escolha os elementos de acordo com seu significado, e não somente pela aparência.

Etapas para criar uma página

  1. Planejar a estrutura do conteúdo;
  2. Escrever o HTML semântico;
  3. Aplicar estilos com CSS;
  4. Adicionar interações com JavaScript;
  5. Testar acessibilidade e responsividade.

Catálogo de HTML, CSS e JavaScript

CSS: aparência da página

O arquivo style.css controla cores, fontes, espaçamentos, tamanhos e a adaptação da página a telas menores.

Seletor
Indica quais elementos receberão o estilo, como .cartao ou body.
Propriedade
É o aspecto alterado, como color, margin ou display.
Valor
Define a configuração da propriedade, como blue, 16px ou grid.
.cartao {
    color: #1f2937;
    padding: 1rem;
}

JavaScript: comportamento da página

O arquivo script.js guarda os dados dos cards, cria a lista na tela e permite pesquisar e filtrar sem recarregar a página.

  • Variável: armazena um valor com const ou let.
  • Função: agrupa instruções reutilizáveis.
  • Evento: reage a ações, como digitar ou clicar.
  • DOM: permite ao JavaScript consultar e modificar o HTML.
