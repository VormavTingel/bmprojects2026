# Nebula Store

Template front-end de uma loja digital de jogos, inspirado na organização visual de marketplaces como a Steam Store.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Layout responsivo
- Sem dependências de frameworks

## Recursos incluídos

- Cabeçalho responsivo
- Barra de navegação e pesquisa
- Banner principal com slider
- Categorias
- Filtros por preço, recursos e sistema
- Ordenação dos jogos
- Cards de produtos
- Simulação de carrinho
- Formulário de newsletter
- Layout para desktop, tablet e celular

## Como executar

Abra o arquivo `index.html` diretamente no navegador.

Para desenvolvimento local, também é possível usar a extensão Live Server no VS Code.
